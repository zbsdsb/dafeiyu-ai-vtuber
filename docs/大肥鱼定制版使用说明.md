# 大肥鱼定制版使用说明

本仓库 fork 自 [Ikaros-521/AI-Vtuber（Luna AI）](https://github.com/Ikaros-521/AI-Vtuber) 的 `v2` 分支，在上游基础上为抖音虚拟主播「大肥鱼」加了一些功能。本仓库沿用上游的 GPL-3.0 许可。上游作者的说明是：个人使用免费，商用需要联系作者授权。

仓库里**不含**以下内容，需要你自己准备：任何 API Key、大肥鱼 Live2D 模型、抖音弹幕监听程序、歌曲文件。

---

## 一、相比上游多了什么

| 功能 | 说明 | 主要文件 |
|---|---|---|
| Fish Audio 配音 | 新增 `fish_audio` 语音合成，默认使用「蓝色大肥鱼」音色 | `utils/audio_handle/my_tts.py` |
| 横屏、竖屏海底场景 | 1920×1080、1080×1920 两套直播画面，背景加 Live2D 角色 | `Live2D/stage-landscape.html`、`Live2D/stage-portrait.html` |
| 台词字幕 | 本机字幕服务（127.0.0.1:5500），场景页里逐字显示台词，说完自动隐藏 | `tools/caption_printer.py`、`Live2D/js/stage-captions.js` |
| 跟着声音动的口型 | 读取主程序实际播放的音量（Windows CoreAudio），驱动角色嘴型 | `tools/songroom_lipsync.py`、`Live2D/js/songroom-lipsync.js` |
| 网易云点歌 | 本地 `song/` 里没有的歌，自动从网易云搜索下载 | `utils/netease_music.py` |
| 点歌限时、断点续播 | 有人在排队时，单首歌最多播 30 秒，切走后排在后面接着播 | `utils/audio.py`（`choose_song` 配置段） |
| 点歌字幕 | 点歌时显示歌名，能匹配到同一版本时显示带时间轴的歌词 | `utils/song_lyrics.py` |
| 空闲背景乐 | 没人说话时自动放背景音乐，角色说话或播点歌时自动让开 | `utils/audio_handle/bgm_player.py`（`bgm` 配置段） |
| 小心心祝福 | 收到小心心礼物时，念出送礼人昵称和一句祝福 | `utils/gift_actions.py` |
| 入场欢迎 | 观众进场时由大模型现场写一句欢迎语，失败时退回模板 | `utils/entrance_welcome.py` |
| 异常推送 | 程序出错时推送到钉钉、Telegram 等，默认关闭 | `utils/notifier.py`（`notify` 配置段） |
| 故障修复 | 首次启动后台时数据分析页崩溃；模型目录缺失时后台起不来；启动后第一句回复卡住；定时任务线程占满一个 CPU 核；Live2D 资源加载卡住；字幕里有 emoji 时报错 | 见各文件内注释 |

## 二、准备工作

1. 一台 Windows 10 或 11 电脑。
2. 一个抖音账号，已经实名，并且有**电脑开播权限**。具体门槛以抖音直播伴侣里的提示为准。
3. 需要安装的软件：
   - [Python 3.11](https://www.python.org/downloads/)。安装时勾选 **Add python.exe to PATH**。
   - [FFmpeg](https://www.gyan.dev/ffmpeg/builds/)，点歌切歌和读取歌曲时长要用。也可以在命令行运行 `winget install Gyan.FFmpeg` 安装。
   - [OBS Studio](https://obsproject.com/)。
   - 抖音直播伴侣，在抖音官网下载。
4. 两个 Key：
   - **大模型**：默认配的是智谱开放平台的免费模型 `glm-4.7-flash`。到 [bigmodel.cn](https://bigmodel.cn) 注册，在「API Key 管理」里创建一个 Key。
   - **配音**：到 [fish.audio](https://fish.audio) 注册，在 API 页面创建一个 Key。如果不想注册，可以在后台把语音合成改成 `edge-tts`。它免费，但声音不是大肥鱼的音色。

## 三、安装

在你想放项目的文件夹里，点一下地址栏，输入 `cmd` 后回车，然后依次运行：

```bat
git clone https://github.com/zbsdsb/dafeiyu-ai-vtuber.git
cd dafeiyu-ai-vtuber
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements\core+platform.lock.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

没装 git 的话，可以在 GitHub 页面点 **Code → Download ZIP**，解压后进入该文件夹，从第三行开始运行。

### 放入大肥鱼模型

模型来自 [xkk6663/dsh-live2d-mao](https://github.com/xkk6663/dsh-live2d-mao)，原作者在说明中写的是「@Mao绒绒家园 免费公皮，非官方二创、非商业、禁止盗用与出售」。

1. 下载这个仓库（Code → Download ZIP）。
2. 把 `澪Agent应用/dist/live2d-pet/models/da-feiyu/` 里的**全部文件**复制到本项目的 `Live2D/live2d-model/大肥鱼/` 下。复制完以后，应该能看到 `Live2D/live2d-model/大肥鱼/大肥鱼.model3.json`。
3. 使用时请在直播间简介或视频里注明模型作者，并且不要用于商业用途。

不想用大肥鱼的话，把 `Live2D/js/model_name.js` 里的模型名改成 `Hiyori`，并在后台「声音与表现」页 Live2D 卡片的「模型名」里选择 `Hiyori`。场景里的表情参数是按大肥鱼调的，换模型后部分表情可能对不上。

### 放入抖音弹幕监听程序

1. 到 [dy-barrage-grab 发行版](https://gitee.com/haodong108/dy-barrage-grab/releases) 下载最新的发行包，不要下载源码包。
2. 解压到本项目的 `tools/DouyinBarrageGrab/`，确认里面有 `WssBarrageServer.exe`。
3. 第一次运行时右键选择「以管理员身份运行」，弹出安装证书的提示时选「是」。
4. 它会占用系统代理。关掉它以后如果上不了网，到「设置 → 网络和 Internet → 代理」里把「使用代理服务器」关掉。

## 四、填 Key

双击 `启动WebUI管理后台.bat`，浏览器打开 http://127.0.0.1:8081 。

- **大模型 Key**：在「人设与大脑 → 模型引擎（LLM）→ OpenAI / Ollama / 通用模型」里，把智谱的 Key 粘贴到 API Key。API 地址 `https://open.bigmodel.cn/api/paas/v4` 和模型 `glm-4.7-flash` 都已经填好了。
- **人设**：在同一张卡片的「预设」里修改。默认是大肥鱼的人设，你可以换成自己的。
- 右下角点「操作 → 保存配置」。
- **Fish 配音 Key**：后台没有这个输入框。先关掉后台窗口，用记事本打开项目里的 `config.json`，搜索 `"fish_audio"`，把 Key 填到 `"api_key": ""` 的引号里，保存后再重新打开后台。也可以不改文件，把 Key 设成系统环境变量 `FISH_API_KEY`。填好后，在「声音与表现 → TTS 语音合成调试」里试听一句。

> 一定要先关后台再改 `config.json`。后台开着时点「保存配置」，会用它内存里的旧值覆盖你在文件里做的修改。

## 五、开播顺序

顺序很重要：弹幕监听必须**在开播之前**启动，否则抓不到弹幕。

1. 以管理员身份运行 `tools/DouyinBarrageGrab/WssBarrageServer.exe`，它运行期间窗口不要关。
2. 双击 `启动WebUI管理后台.bat`，在后台右下角点「操作 → 一键运行」。
3. 启动字幕和口型服务（在项目文件夹里打开 PowerShell）：

   ```powershell
   powershell -NoProfile -File tools\start-caption-printer.ps1
   powershell -NoProfile -File tools\start-songroom-lipsync.ps1
   ```

4. 在 OBS 里添加一个「浏览器」来源：
   - 竖屏：`http://127.0.0.1:12345/Live2D/stage-portrait.html`，宽 1080、高 1920。
   - 横屏：`http://127.0.0.1:12345/Live2D/stage-landscape.html`，宽 1920、高 1080。
   - 在「设置 → 视频」里，把基础分辨率和输出分辨率都设成和来源一样的尺寸。
5. 在 OBS 里点「启动虚拟摄像机」。
6. 打开抖音直播伴侣，添加素材时选「摄像头 → OBS Virtual Camera」。声音要采集**电脑声音**，因为角色的声音是从电脑扬声器播放的，虚拟摄像头本身不带声音。
7. 在直播伴侣里开播，并按平台要求做 AI 或虚拟人声明（见第六节）。

`一键启动主播程序.bat` 会同时启动弹幕监听和主程序，适合不打开后台的情况。如果已经在后台点过「一键运行」，就不要再双击它，否则会启动两个主程序。

**不要运行** `2-1.强制更新至主线版本（得先安装git）.bat`。它会执行 `git reset --hard`，把你本地的修改全部覆盖。

## 六、合规提醒

依据《抖音关于人工智能生成内容的平台规范暨行业倡议》，以及 2025 年 9 月 1 日起施行的《人工智能生成合成内容标识办法》：

- 直播画面和简介要明确标识这是 AI 或虚拟主播。
- 虚拟形象需要在抖音平台注册，背后的真人需要实名认证。
- 平台规定虚拟人直播必须由真人驱动、实时互动，不允许完全由 AI 驱动。开播期间你要守在电脑前，能随时接管和回复。
- 不要用 AI 冒充真人或他人形象；点歌和背景乐的版权风险由你自己承担。

## 七、常见问题

| 现象 | 先查这里 |
|---|---|
| 收不到弹幕 | 弹幕监听是不是先于直播伴侣启动的？是不是以管理员身份运行的？平台是不是选了「抖音」？ |
| 关掉弹幕监听后上不了网 | 系统代理没有恢复，到「设置 → 网络和 Internet → 代理」里关掉 |
| 角色嘴在动，观众却听不到 | 直播伴侣没有采集电脑声音，或者 Windows 的默认播放设备选错了 |
| 回复报 401 | Key 填错了或者过期了；改完记得点「保存配置」，再重新「一键运行」 |
| 后台提示「未找到模型文件」 | `Live2D/live2d-model/大肥鱼/` 下面没有模型文件，按第三节放进去 |
| 点歌时总说「还没学会唱」 | 网易云搜索被限流了，过两分钟再试；也可以把 mp3 直接放进 `song/` 文件夹 |
| 字幕不显示 | 5500 端口的字幕服务没有启动，见第五节第 3 步 |
